# Security Policy

## Supported Versions

HA StatusFrame is a personal DIY project provided
as a reference implementation.

Security updates are provided on a best-effort basis.

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |
| < 1.0   | No        |

## Reporting a Vulnerability

If you discover a security vulnerability, please do
not disclose sensitive details in a public GitHub Issue.

Instead, use GitHub's private vulnerability reporting
feature, if enabled for this repository.

Please include:

- A description of the vulnerability
- Steps to reproduce the issue
- Potential security implications
- Suggested fixes, if available

## Security Recommendations

- Never publish passwords, API keys or MQTT credentials.
- Use strong authentication for your MQTT broker.
- Keep Home Assistant, ESPHome and Node-RED updated.
- Restrict access to your local network and devices.
- Review configuration files before publishing them.

## Disclaimer

HA StatusFrame is provided as-is, without warranty.

Users are responsible for securing their own
installations and network environments.
