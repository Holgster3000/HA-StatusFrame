# Contributing to HA StatusFrame

Thank you for your interest in HA StatusFrame!

This project documents a real, working ESP32-based LED
status display using Home Assistant, ESPHome, Node-RED,
and MQTT.

Contributions, feedback, and improvement suggestions
are welcome.

## Reporting Issues

If you encounter a problem, please open a GitHub Issue.

When reporting a problem, please include:

- A clear description of the issue
- The expected and actual behavior
- Relevant ESPHome or Node-RED logs, if available
- Your hardware configuration
- Steps to reproduce the problem

Please remove passwords, API keys, MQTT credentials,
and other sensitive information before sharing logs
or configuration files.

## Suggesting Improvements

Ideas for improving the project are welcome!

You can open an Issue to suggest:

- Additional LED status indicators
- Improvements to the Node-RED flow
- ESPHome enhancements
- Hardware improvements
- Documentation updates

## Pull Requests

Pull requests are welcome.

Before submitting a pull request:

1. Describe the purpose of your changes.
2. Keep modifications focused and easy to understand.
3. Test your changes whenever possible.
4. Update the documentation if necessary.
5. Avoid including personal data or credentials.

## Project Scope

HA StatusFrame currently documents the original,
working hardware and software configuration.

It is not intended to be a universal plug-and-play
solution at this stage.

The existing ESPHome configuration and Node-RED flow
serve as a reference implementation.

Changes should preserve the functionality of the
original setup whenever possible.

## Questions and Discussions

For questions, feedback, or general discussion,
please use GitHub Issues.

Thank you for helping improve HA StatusFrame!
